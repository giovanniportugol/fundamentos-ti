# Cloud Computing - Conceitos Básicos

## Sobre

Este arquivo registra meus estudos iniciais sobre cloud computing, também conhecida como computação em nuvem.

## O que é cloud computing?

Cloud computing é o uso de recursos de tecnologia pela internet, como armazenamento, servidores, bancos de dados, redes, softwares e aplicações.

Em vez de depender apenas de equipamentos físicos locais, a empresa ou usuário pode utilizar serviços disponíveis em plataformas de nuvem.

## Exemplos de serviços em nuvem

- Armazenamento de arquivos
- Hospedagem de sites e sistemas
- Bancos de dados
- Máquinas virtuais
- Backup em nuvem
- Aplicações online
- Serviços de segurança

## Modelos comuns de cloud

### IaaS - Infraestrutura como Serviço

Fornece recursos como servidores, redes e armazenamento.

### PaaS - Plataforma como Serviço

Fornece uma plataforma para desenvolvimento, testes e implantação de aplicações.

### SaaS - Software como Serviço

Fornece softwares prontos para uso pela internet, como e-mail, sistemas online e ferramentas corporativas.

## Importância para TI

Conhecimentos básicos de cloud computing ajudam a compreender como empresas utilizam infraestrutura, sistemas e serviços pela internet.
