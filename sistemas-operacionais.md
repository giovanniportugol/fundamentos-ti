# Sistemas Operacionais - Conceitos Básicos

## O que é um sistema operacional?

Um sistema operacional é o software responsável por controlar o funcionamento do computador, gerenciar recursos e permitir a interação entre o usuário, os programas e o hardware.

## Exemplos de sistemas operacionais

- Windows
- Linux
- macOS
- Android
- iOS

## Funções principais

- Gerenciar arquivos e pastas
- Controlar memória e processamento
- Executar programas
- Gerenciar dispositivos como teclado, mouse, impressora e monitor
- Controlar usuários e permissões
- Permitir conexão com redes

## Importância para suporte técnico

Conhecer sistemas operacionais é importante para identificar problemas, configurar recursos, orientar usuários e realizar procedimentos básicos de manutenção e suporte.

## Objetivo do estudo

Fortalecer minha base em Tecnologia da Informação, suporte técnico e infraestrutura, desenvolvendo conhecimentos fundamentais sobre sistemas operacionais.
