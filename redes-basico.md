# Redes de Computadores - Conceitos Básicos

## O que é uma rede de computadores?

Uma rede de computadores é um conjunto de dispositivos conectados para compartilhar informações, arquivos, sistemas, internet e recursos.

## Exemplos de dispositivos em uma rede

- Computadores
- Notebooks
- Celulares
- Impressoras
- Roteadores
- Servidores

## Conceitos importantes

### IP

O endereço IP identifica um dispositivo dentro de uma rede.

### Roteador

Equipamento responsável por conectar dispositivos à rede e permitir acesso à internet.

### Switch

Equipamento usado para conectar vários dispositivos dentro de uma rede local.

### Wi-Fi

Tecnologia que permite conexão sem fio entre dispositivos e a rede.

## Objetivo do estudo

Compreender os conceitos iniciais de redes de computadores para fortalecer minha base em Tecnologia da Informação, suporte técnico e infraestrutura.
