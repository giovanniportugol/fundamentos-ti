# Comandos Básicos de Terminal

## Sobre

Este arquivo registra comandos básicos utilizados em estudos de sistemas operacionais, redes e suporte técnico.

## Comandos no Windows

- `dir` — lista arquivos e pastas
- `cd` — acessa uma pasta
- `cls` — limpa a tela
- `ipconfig` — mostra informações de rede
- `ping` — testa comunicação com um endereço
- `mkdir` — cria uma nova pasta
- `del` — exclui arquivos

## Comandos no Linux

- `ls` — lista arquivos e pastas
- `cd` — acessa uma pasta
- `clear` — limpa a tela
- `pwd` — mostra o diretório atual
- `mkdir` — cria uma nova pasta
- `rm` — remove arquivos
- `ping` — testa comunicação com um endereço

## Importância para TI

Conhecer comandos básicos de terminal ajuda em atividades de suporte técnico, diagnóstico de rede, organização de arquivos e administração inicial de sistemas.

Fortalecer minha base em Tecnologia da Informação, suporte técnico, sistemas operacionais e redes.
